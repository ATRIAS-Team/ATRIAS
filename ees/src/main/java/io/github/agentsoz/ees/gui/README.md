Algoritms for questions are stored in Algorithms class.

In Main class there is a field initDate, that needs a DateTime of the historical begin of the simulation.

You can add more questions in questionInput() method 

You can add the answers in answers() methods inside of the switch() block. Make sure that case and question numbers match.

IMPORTANT:  
When a class in ess is modified(DecisionTask, Trip etc.), you need to modify its duplicate in model package as well.
It is not necessary if it doesn't affect the answers to user questions.
